## 2. Loyiha nima haqida

**Algoritmi** — o'zbek tilidagi bepul interaktiv informatika platformasi, 1-sinfdan universitetgacha. Nom Muhammad al-Xorazmiyning lotincha ismidan olingan (*Algoritmi de numero Indorum*).

Har bir mavzu jonli diagramma. Dars tartibi:

```
vaziyat → taxmin → qadamlar (muammo → yechim → texnika → … → xulosa) → topshiriqlar → test → faktlar
```

Konsepsiya (`docs/konsepsiya.md`) uchta loyihadan olingan saboqlarga asoslangan:

| Namuna | Nima olindi | Nima takrorlanmaydi |
|---|---|---|
| designed-to-scale | Darslar ma'lumot sifatida, bitta SVG dvigatel, jonli metrikalar | — |
| fanlab.uz | Vaziyat → Taxmin → Tajriba → Xulosa, Telegram login, maktab reytingi | — |
| osonstudio IQ | Generatorlar, kunlik challenge | Javoblar ochiq JS faylda, sertifikat URL'da, reyting faqat brauzerda |

**Asosiy tamoyillar** (`CLAUDE.md`):
1. Darslar = ma'lumot (JSON), dvigatelga tegmasdan yangi dars qo'shiladi.
2. Test javoblari kliyentda saqlanmaydi.
3. Yengil: Vite + TypeScript, framework'siz.
4. Avval mobil: 360px.
5. Ranglar faqat CSS o'zgaruvchilari orqali.

**MVP maqsadi:** «03. Internet qanday ishlaydi» moduli, 7 ta dars.

## 6. Dars sxemasi (yangi)

Asosiy o'zgarish: **sahna obyektlari va aloqalari darsda bir marta e'lon qilinadi**, qadamlar esa ulardan keraklisini nomi bilan tanlaydi. Shunda obyekt qadamdan qadamga o'z joyida qoladi, kamera esa silliq kattalashadi yoki kichrayadi.

```jsonc
{
  "id": "telegram-xabar",
  "modul": "internet",
  "daraja": "m7",
  "daqiqa": 12,
  "sarlavha": "...",
  "vaziyat": "...",
  "taxmin": { "savol": "...", "variantlar": ["...", "...", "..."] },   // to'g'ri javob YO'Q
  "metrikalar": [{ "id": "masofa", "nom": "Masofa", "birlik": "km" }],
  "obyektlar": {
    "telefon": { "tur": "telefon", "x": 0, "y": 0, "m": [0, 0], "yorliq": "Aziz", "izoh": "Toshkent" }
  },
  "aloqalar": {
    "wifi": { "dan": "telefon", "ga": "router", "tur": "wifi", "yorliq": "Wi-Fi" }
  },
  "qadamlar": [{
    "bob": "texnika",
    "sarlavha": "...",
    "matn": ["..."],
    "eslatma": { "tur": "insight", "matn": "..." },
    "metrika": { "masofa": 0.01 },          // faqat o'zgarganlari
    "sahna": {                              // berilmasa — oldingi qadam sahnasi
      "obyektlar": ["telefon", "router"],
      "aloqalar": ["wifi"],
      "oqimlar": [{ "yol": ["wifi"], "tezlik": 1.5, "tur": "oddiy" }],
      "urgu": ["router"]
    }
  }],
  "topshiriqlar": [{ "id": "...", "matn": "..." }],
  "test": [{ "id": "q1", "savol": "...", "variantlar": ["..."] }],      // javob YO'Q
  "faktlar": ["..."],
  "ai": { "javob": "AI aytgan xato gap", "savol": "Bu to'g'rimi?" }

```

### Ruxsat etilgan qiymatlar

| Maydon | Qiymatlar |
|---|---|
| `daraja` | `m14`, `m56`, `m7`, `m89`, `m1011`, `uni` |
| `bob` | `muammo`, `yechim`, `texnika`, `insight`, `xulosa` |
| `eslatma.tur` | `warn` (Diqqat), `tip` (Maslahat), `insight` (Bilasizmi?) |
| obyekt `tur` | `telefon`, `noutbuk`, `router`, `provayder`, `server`, `dns`, `bulut`, `yoldosh`, `kuzatuvchi`, `savol`, `bitlar`, `paket` |
| aloqa `tur` | `kabel`, `wifi` (harakatlanuvchi nuqtalar), `okean` (qalin, feruza), `havo` (punktir) |
| oqim `tur` | `oddiy`, `bit`, `sorov` (DNS), `tasdiq` (ACK), `xato` (yo'qoladi), `qulf` (shifrlangan) |

### Meros qoidalari
- **Sahna:** `sahna` berilmagan qadam oldingi qadam sahnasini oladi.
- **Metrika:** qadamdan qadamga yig'iladi, faqat o'zgarganini yozish kifoya.

### Koordinatalar
- 1 katak = 90 SVG birligi, qo'shni obyektlar odatda 2 katak oralig'ida.
- `m: [x, y]` — telefon va kvadratga yaqin ekran uchun alohida joylashuv. Yo hamma obyektda bo'ladi, yo hech birida.
- `m` berilmasa, keng sahna tor ekranda avtomatik 90° buriladi.

## 7. Sahna dvigateli qanday ishlaydi

`src/engine/scene.ts` — `SahnaDvigateli` klassi.

1. **Oldindan chizish.** Dars ochilganda barcha obyekt va aloqalar bir marta yaratiladi va yashirin turadi.
2. **`korsat(sahna)`.** Har qadamda qaysi obyekt va aloqalar ko'rinishi, qaysilari ajratib ko'rsatilishi (urg'u) va qaysi oqimlar yurishi beriladi.
3. **Bitta `requestAnimationFrame` halqasi.** Joylashuv, shaffoflik va kamera (viewBox) maqsadga eksponensial yaqinlashadi. Animatsiya o'rtasida yangi qadam bosilsa ham uzilmaydi.
4. **Halqa o'zi to'xtaydi.** Hech narsa harakatlanmayotgan yoki pauza bosilgan bo'lsa, halqa ishlamaydi va batareya tejaladi.
5. **Avtomatik kamera.** Kamera ko'rinadigan obyektlarni sig'diradi: eng kichik o'lcham bor, masshtab ≤ 0,87, tepada pauza tugmasi uchun joy qoldiriladi.
6. **Ixcham rejim.** Konteyner kengligi < 560px yoki eni/bo'yi nisbati < 1,35 bo'lsa, `m` koordinatalari va kattaroq yozuv ishlatiladi.
7. **Paketlar.**
   - Aloqalar zanjiri bo'ylab 230 birlik/soniya tezlikda yuradi.
   - `xato` paketi yo'lning belgilangan qismida qizil ✕ bo'lib yo'qoladi.
   - Bir vaqtda ko'pi bilan 80 ta paket bo'ladi.
8. **Arzon telefonlar uchun.** Soya `filter` bilan emas, oddiy to'rtburchak bilan chiziladi.
9. **«Harakatni kamaytirish» sozlamasi.** Bu sozlama yoqilgan bo'lsa, har bir oqimdan bittadan qotgan paket ko'rsatiladi, animatsiyalar o'chadi.
10. **`ResizeObserver`.** Ekran o'lchami o'zgarsa (masalan, telefon buriladi), joylashuv silliq qayta quriladi.

**Metrikalar paneli** (`metrics.ts`):
- Raqamlar 600 ms ichida silliq o'zgaradi, o'zgargan metrika yonib-o'chadi.
- Sonlar o'zbekcha yoziladi: `11 000`, `0,01`.

## 8. Dars tekshiruvchisi

`src/engine/validate.ts` + `vite.config.ts` dagi plagin. Har bir `src/lessons/*.json` uchun ishlaydi:
- **`npm run build`:** xato bo'lsa build to'xtaydi va hamma xatolar ro'yxati chiqadi;
- **`npm run dev`:** brauzerda xato oynasi ko'rinadi.

**Nimalarni ushlaydi:**
- tip va ruxsat etilgan qiymatlar (`bob`, `daraja`, obyekt/aloqa/oqim turlari);
- **noma'lum maydonlar** — yozuv xatolarini ham, testga yozilgan `togri`/`javob` kalitini ham ushlaydi (javob sizib chiqmasligi kafolati);
- havolalar: aloqa uchlari mavjudmi, qadamdagi aloqaning ikkala uchi shu qadamda ko'rinadimi;
- oqim zanjiri uzilmaganmi, oqimdagi aloqa shu qadamda bormi;
- `urgu` faqat ko'rinadigan obyektga beriladimi, `yoqolish` faqat `xato` turidami (0–1);
- metrika id'lari `dars.metrikalar` ichida bormi;
- id'lar takrorlanmaganmi, birinchi qadamda sahna bormi, `m` hammada yoki hech birida emasmi.

**Sinov natijasi:** ataylab buzilgan dars (`"bob": "muamo"`, uzilgan zanjir, testda `"togri": 1`) bilan build to'xtadi. Tekshiruvchi 5 ta xatoni aniq yo'li bilan ko'rsatdi.

## 11. Ekranlar

### Landing (`#/`)
1. **Navigatsiya** — yopishqoq, shishasimon xira fon. Bo'limlarga silliq o'tish, tema tugmasi, «Boshlash».
2. **Hero** — sarlavha (gradientli urg'u bilan), tavsif, ikki tugma, raqamlar (11 modul · 1–11 sinf · 0 so'm).
   - O'ngda **haqiqiy dvigatelda ishlayotgan jonli dars**: 8 ta qadam har 4,2 soniyada almashadi.
   - Sahifa ko'rinmay turganda yoki tab yashirin bo'lsa, almashish to'xtaydi.
   - Avval to'xtagan joyingiz bo'lsa, tugma «Davom etish: N-qadam» bo'ladi.
3. **Afzalliklar** — bepul, o'zbek tilida, ro'yxatdan o'tmasdan, telefonda ham.
4. **Metodika** — Vaziyat → Taxmin → Tajriba → Kashfiyot.
5. **AI davri ko'nikmalari** — 8 ta.
6. **O'quv xaritasi** — faol modul katta kartochkada (progress, darslar ro'yxati), qolgan 10 modul tavsif va sinf bilan.
7. **«Algoritm» so'zi Xorazmdan** — to'q bo'lim, *Algoritmi de numero Indorum* iqtibosi.
8. **Halollik** — javoblar sahifada yo'q, shaxsiy ma'lumot so'ralmaydi, reklama yo'q.
9. **Yakuniy chaqiruv** va **footer**.

### Taxmin (`#/<dars>`)

### Yakun (`#/<dars>/yakun`)
